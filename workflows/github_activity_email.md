# GitHub Activity Email

## Objective

Send an email summary of recent GitHub activity to Hans. The summary is generated by AI analyzing actual code diffs — not commit messages.

## Required Inputs

| Input | Source | Default |
|-------|--------|---------|
| Recipient | `GITHUB_ACTIVITY_RECIPIENT` in `.env` | `hans.preinfalk.davila@gmail.com` |
| Composio user | `COMPOSIO_USER_ID` in `.env` | `funny-news` |
| Gemini API key | `GOOGLE_GENERATIVE_AI_API_KEY` in `.env` | required |
| Activity window | `GITHUB_ACTIVITY_HOURS` in `.env` | `24` (hours) |
| Max repos scanned | `GITHUB_ACTIVITY_MAX_REPOS` | `10` |
| Max commits per repo | `GITHUB_ACTIVITY_MAX_COMMITS` | `5` |

## Prerequisites (one-time)

Both GitHub and Gmail must be connected for the Composio user (`COMPOSIO_USER_ID`):

```bash
npm run tool tools/connect_github.ts
npm run tool tools/connect_gmail.ts
```

Open each printed OAuth URL and authorize the account. The scripts wait up to 5 minutes for completion.

## Execution

Run the end-to-end tool:

```bash
npm run tool tools/send_github_activity_email.ts
```

The tool will:

1. Verify GitHub and Gmail connections for `COMPOSIO_USER_ID`
2. Fetch the authenticated GitHub user profile
3. List repositories pushed within the activity window (default: last 24 hours)
4. Fetch full commit diffs via `GITHUB_GET_A_COMMIT` (patches + file stats)
5. Send diffs to Gemini (`gemini-2.0-flash-001`) for an AI-written summary of what was actually done in the code
6. Format an HTML dashboard email (The Deployment Company design)
7. Send the email via Composio/Gmail

## Expected Output

Email to `hans.preinfalk.davila@gmail.com` with:

- Subject: `GitHub Activity — {username} — {date}`
- Branded HTML dashboard: stat cards, AI "At a Glance" summary, active repos table, and code changes timeline
- No account or notifications sections

## Edge Cases

| Issue | Handling |
|-------|----------|
| No GitHub/Gmail connection | Tool exits with a message pointing to the connect script |
| Missing `GOOGLE_GENERATIVE_AI_API_KEY` | Tool exits with setup instructions |
| Repo returns 404 or empty | Skipped; other repos still included |
| Commit has no patch (large/binary) | File metadata included; patch omitted |
| No activity in window | Email still sends with AI "no changes" summary |
| Rate limits | Reduce `GITHUB_ACTIVITY_MAX_REPOS`; re-run after a few minutes |
| Large diffs | Patches truncated per-file and total context capped before AI analysis |

## Scheduling (optional)

To send daily, add a GitHub Actions workflow or cron job that runs:

```bash
npm run tool tools/send_github_activity_email.ts
```

Ensure `COMPOSIO_API_KEY`, `COMPOSIO_USER_ID`, `GOOGLE_GENERATIVE_AI_API_KEY`, and `GITHUB_ACTIVITY_RECIPIENT` are set as repository secrets.
